# Hermes Dashboard Themes

A collection of 10 custom themes for the [Hermes Agent](https://hermes-agent.nousresearch.com/) web dashboard, created for the Nous Research hackathon.

## Themes

### 1. Matcha 🍵
Calm Japanese tea shop aesthetic with soft greens and warm cream accents.
- Palette: Deep forest green + soft sage
- Font: Zen Kaku Gothic New
- Vibe: Minimal, peaceful, organic

### 2. Synthwave 🎶
80s neon grid with magenta accents on deep purple-black.
- Palette: Electric magenta + cyan highlights
- Font: Orbitron
- Layout: Cockpit with notched cards and grid overlay
- Vibe: Retro-futuristic, bold, energetic

### 3. Nord Ice ❄️
Arctic polar theme based on the popular Nord color palette.
- Palette: Cool blues + ice white
- Font: Inter + JetBrains Mono
- Vibe: Clean, professional, calm

### 4. Tokyo Night 🏯
Cyberpunk Tokyo city lights with deep blues and electric pinks.
- Palette: Electric blue + violet + soft pinks
- Font: Noto Sans JP + Fira Code
- Vibe: Urban, neon, modern

### 5. Coffee Shop ☕
Warm café aesthetic with rich browns, creams, and amber accents.
- Palette: Warm brown + caramel + cream
- Font: Lora (serif)
- Layout: Spacious with elegant curves
- Vibe: Cozy, warm, literary

### 6. Desert Mirage 🏜️
Warm desert tones with sandy beiges and sunset oranges.
- Palette: Sand + terracotta + amber
- Vibe: Warm, earthy, serene

### 7. Kuwait Pearl 🇰🇼
Local Kuwait aesthetic with pearl whites and azure blues.
- Palette: Pearl white + azure blue + gold accents
- Vibe: Elegant, cultural, refined

### 8. Matrix Terminal 🖥️
Classic green terminal hacker vibe.
- Palette: Black + bright green
- Font: Monospace
- Vibe: Retro, tech, hacker

### 9. Midnight Oil 🌙
Deep blue productivity theme for late-night sessions.
- Palette: Midnight blue + soft white
- Vibe: Focused, calm, professional

### 10. Sakura Bloom 🌸
Soft pink cherry blossom aesthetic.
- Palette: Soft pink + ivory + sage green
- Vibe: Gentle, spring, delicate

## Installation

```bash
# Clone the repo
git clone https://github.com/minutechreview/hermes-dashboard-themes.git

# Copy themes to your Hermes dashboard themes directory
cp hermes-dashboard-themes/*.yaml ~/.hermes/dashboard-themes/

# Refresh the dashboard and select from the theme picker
```

## Requirements

- Hermes Agent with dashboard support (`hermes dashboard`)
- Internet connection (for Google Fonts loading)
